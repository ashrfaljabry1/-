# تجميعة الشيخ أشرف للأذكار

تطبيق ويب شامل للأذكار الإسلامية اليومية مع ميزات متقدمة.

## الميزات

- **أقسام متعددة**: أذكار الصباح، المساء، النوم، الاستيقاظ، بعد الصلاة، المسجد، الطعام، السفر، الحماية، وأذكار متنوعة
- **عداد تفاعلي**: لكل ذكر مع إمكانية تقليل التكرارات وإعادة التعيين
- **المفضلة**: إمكانية إضافة الأذكار إلى المفضلة وعرضها في قسم خاص
- **البث الصوتي**: استخدام Text-to-Speech لتلاوة الأذكار
- **نسخ النص**: نسخ نص الذكر إلى الحافظة
- **بحث فوري**: البحث في جميع الأذكار
- **تخصيص الواجهة**: وضع الليل/النهار، تكبير/تصغير الخط
- **تتبع التقدم**: شريط تقدم يظهر إنجازك اليومي
- **حفظ التلقائي**: حفظ حالة التقدم في المتصفح (localStorage)

## كيفية الاستخدام

1. افتح الموقع في أي متصفح حديث
2. اختر قسم الأذكار المطلوب من شريط التنقل
3. اضغط على زر "-" لتقليل عدد التكرارات
4. استخدم الأزرار الإضافية للتخصيص:
   - ♥ إضافة إلى المفضلة
   - 🔊 تشغيل النص صوتياً
   - 📋 نسخ النص
5. اضغط على زر إعادة التعيين ⟲ لإعادة العداد إلى قيمته الأصلية

## كيفية إضافة أذكار جديدة

لإضافة أذكار جديدة، قم بتعديل كائن `azkarData` في JavaScript:

```javascript
// مثال لإضافة ذكر جديد
azkarData.morning.push({
    text: "النص الكامل للذكر",
    description: "وصف قصير للذكر",
    count: 3, // عدد التكرارات الموصى بها
    reference: "المصدر الشرعي"
});
